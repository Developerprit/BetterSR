录屏，本该如此温柔

BetterSR 为 Windows 打造，拒绝臃肿与工业感。浅粉配色搭配半透明背景，让每一次录制都像在创作。

支持全屏、区域、窗口三种录制模式；系统音频与麦克风独立开关；20+ 全局快捷键覆盖录制全流程。

开机自启、托盘常驻、每日一言——打开它，就像遇见一个老朋友的问候。

核心特性

三种录制模式

全屏、区域、窗口，一键切换。区域录制支持可视化拖拽选区。

灵活音频控制

系统音频与麦克风可独立开关，实时混音输出到 MP4。

20+ 全局快捷键

录制、暂停、截图、切换音频，全程无需离开当前工作区。

浅色 / 深色主题

一键切换日夜间模式，保护眼睛，也保护心情。

开机自启 + 托盘

常驻系统托盘，随时开始录制；支持开机自动启动。

每日一言

每次启动从一言 API 随机获取一句话，给创作一点灵感。
